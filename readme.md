各位同學大家好！歡迎來到地政士考試**《平均地權條例及其施行細則》完整攻略班**。

在正式開始上課之前，老師先幫大家建立一個最重要的考情觀念：**《平均地權條例》是地政士考試的「跨科超級大魔王」，也是「搶分大補丸」**。它在**〈土地法規〉**與**〈土地稅法規〉**兩大考科中都會大量出題；加上民國 112 年施行的「平均地權條例 2.0（打炒房五大新制）」，至今仍是命題委員最愛的申論題熱點。

這套課程老師會用**「全白話解析法條」＋「母法與施行細則同步整合」＋「真實案例與比較表格」**的方式，帶大家按部就班，把生硬的法條轉化成考場上寫得出來、拿得到高分的申論實力。

以下為各位同學規劃的**十堂課完整課程大綱**：

---

## 一、 課程設計與學習特色

1. **母法與施行細則無縫整合**：讀母法條文時，直接帶入對應的《平均地權條例施行細則》（共 110 條）及必要相關子法／關聯法規（如《土地稅法》、《土地徵收條例》），不用自己前後翻找。
2. **白話翻譯＋生活案例**：每一項重要制度都會先講「立法目的（政府為什麼要這樣規定？）」，再舉買賣、報稅、重劃、預售屋交易等實務案例，讓法條立體化。
3. **地政士全申論導向**：針對地政士考試「全申論題」的特性，每單元都會標註**核心考點（★星級）**、**易混淆比較表**與**擬答關鍵字**。

## 三、 上課方式與後續建議

每堂課我們會固定採用以下四步節奏進行，讓大家吸收最有效率：
1. **架構鳥瞰**：先用 1 分鐘看懂本堂課在整個法規體系中的位置。
2. **白話精講**：逐條（或依主題群組）將母法＋施行細則翻成白話，搭配**實務案例**拆解。
3. **考點對決**：整理「易混淆觀念比較表」與「口訣記憶法」。
4. **課後小測驗**：提供 1～2 題地政士申論模擬題與答題重點，確認完全吸收。
